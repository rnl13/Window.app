# Historical wind, release 2026-09-13

Four existing spots: Agger Tange, Hanstholm, Møn Fyr, Nørre Vorupør. ERA5 only (not changing best-match models), 10m scalar wind speed m/s and wind direction FROM. 2016–2025, the ten completed years preceding this release. Static snapshot; not represented as a continuously refreshing trailing period. Each file retains requested coordinates, actual provider grid coordinates, original fetch URL/date and compressed source hash. No station validation or local correction.

Raw provenance/data: data/history/*.json.gz. Public derived summaries: public/history/*.json. Rebuild: python scripts/build-history.py. Script reuses existing source snapshots. The Hanstholm snapshot reuses the earlier Window feasibility download. Other three were fetched for this release. Raw files are retained in the source repository, not exposed through public assets. Attribution: ERA5 (Copernicus/ECMWF) via Open-Meteo, https://open-meteo.com/en/docs/historical-weather-api . Existing free API retrieval is a noncommercial pilot; arrange an appropriate data-service plan before commercial operation. Data attribution follows Open-Meteo's CC BY 4.0 data terms.

UTC hourly labels converted to Europe/Copenhagen; select local year/month. All-day or local hourly labels 10 through 17 (10:00–18:00 interval), explicitly not an astronomical daylight filter. DST expected hours use timestamp differences at local month boundaries. Because the original request begins at 2016-01-01 00 UTC, January 2016 lacks the first local hour; it is omitted, not imputed. There are 87,671 valid hourly samples per spot, out of 87,672 expected local hours for 2016–2025. Daytime subset is complete.

Mean is arithmetic scalar mean of valid speeds, hourly-weighted across all selected years. >= threshold numerator divided by the same valid-speed denominator (threshold 4–20 m/s in integer increments). Display conversion to knots uses 1.94384. Changing threshold changes fraction only, not mean, direction distribution or other charts. Eight equal 45-degree sectors centered N/NE/...; excludes speeds below 0.5m/s and invalid direction values. Shows modal sector, not arithmetic degree average. Year and diurnal views use same month/time selection and valid denominators. Rounded derived means at .001 m/s, displayed .1.

Verification: all 96 spot/month/time-mode aggregates checked against sums of yearly counts and weighted yearly means; count <= expected; monotone threshold counts; direction counts sum; leap February daytime count 2264; build. Not visually tested on a physical phone. Grid values may materially differ between nearby coastal spots and must not be interpreted as exact launch conditions, kiteable days or forecast confidence. No modification of score or push rules.
